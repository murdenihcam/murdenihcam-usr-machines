Open the repo's docs folder (Chrome or Edge: “Open docs folder”). Edit any text; the preview on the right updates as you type. Then “Review & save” shows every change before writing site-text.js, machines.js and the version tags in index.html.

Firefox/Safari: use “…or pick docs folder” and choose the docs folder (the browser may ask to “upload” it: nothing leaves your computer). Or use “…or pick files” and choose site-text.js, machines.js and index.html from docs, together or one at a time. Saving then downloads the changed files for you to copy back into docs/.

HTML is allowed in the texts (links, <b>, <code>). Knob positions, logos and file names are not editable here.
